# 交互式导航文献调研

**调研时间：** 2026-04-11  
**调研人：** 任大师  

---

## 1. 调研背景与目标

本项目旨在在传统机器人导航（语义地图引导 / SLAM 框架）基础上，增加**环境交互能力**——机器人能够感知并操作场景中的可交互对象（门、冰箱、衣柜等），以完成更复杂的导航与探索任务。

核心研究问题：
1. 如何在语义地图中表征可交互对象的交互属性？
2. 如何将导航与操作（manipulation）统一在一个框架中？
3. 如何利用 foundation model（VLM/LLM）实现开放词汇的交互感知与规划？

## 2. 文献分类与分析

### 2.1 语义地图与场景表征

#### [1] Semantic Mapping in Indoor Embodied AI — A Survey
- **arXiv:** 2501.05750 (2025.01)
- **作者:** Sonia Raychaudhuri, Angel X. Chang
- **核心贡献:** 对 embodied AI 中语义地图构建方法的全面综述。按结构表征（空间网格、拓扑图、稠密点云、混合地图）和信息编码（隐式特征 vs 显式环境数据）两个维度分类。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ 本项目需要在语义地图中增加"交互层"，该综述为地图表征选型提供了理论基础。关键发现：领域正在向 open-vocabulary、可查询、task-agnostic 的地图表征发展。

#### [2] HOV-SG: Hierarchical Open-Vocabulary 3D Scene Graphs
- **arXiv:** 2403.17846 (2024.03)
- **作者:** Abdelrhman Werby et al. (Uni Freiburg)
- **核心贡献:** 提出层次化 open-vocabulary 3D 场景图，构建 floor → room → object 的层级结构，每层都有 open-vocabulary 特征。支持跨楼层导航。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ 场景图层级结构可以直接扩展——在 object 节点上增加"交互属性"边（如 door → can_open → room_B），形成我们设想的"地图交互层"。

#### [3] Open Scene Graphs for Open World Object-Goal Navigation (OSG Navigator)
- **arXiv:** 2508.04678 (2025.08) / 2407.02473
- **作者:** Joel Loo, Zhanxin Wu, David Hsu (NUS)
- **核心贡献:** 提出 Open Scene Graph (OSG) 表征，使用环境类型的 schema 模板自动构建拓扑-语义地图。利用 LLM 进行空间推理，实现 zero-shot ObjectNav。
- **与本项目的关联:** ⭐⭐⭐⭐ OSG 的 schema 机制可以扩展为"交互 schema"（如 kitchen 场景中的 fridge、cabinet 标注为可交互）。

#### [4] DualMap: Online Open-Vocabulary Semantic Mapping
- **arXiv:** 2506.01950 (2025.06)
- **作者:** Jiajun Jiang et al.
- **核心贡献:** 双地图表征——全局抽象地图（高层候选选择）+ 局部精确地图（精确到达）。支持在线场景映射和动态变化检测。
- **与本项目的关联:** ⭐⭐⭐⭐ 双地图思想可以借鉴：全局地图标注可交互区域，局部地图处理具体交互操作。

#### [5] Semantic Environment Atlas (SEA)
- **arXiv:** 2410.09081 (2024.10)
- **作者:** Nuri Kim et al. (Seoul National University)
- **核心贡献:** 语义图地图，编码 place-object 关系。在 ObjectNav 上实现了 39.0% 的成功率（SOTA +12.4%）。
- **与本项目的关联:** ⭐⭐⭐ place-object 关系可以扩展为 place-interaction_object-reachable_room 三元组。

### 2.2 移动操作与交互导航

#### [6] Interactive Navigation with Adaptive Non-prehensile Mobile Manipulation
- **arXiv:** 2410.13418 (2024.10)
- **作者:** Cunxi Dai et al. (CMU)
- **核心贡献:** **直接相关！** 提出 interactive navigation 框架，通过非抓取式移动操作（推动）来清除导航路径上的可移动障碍物。学习 SE(2) 动态模型来预测物体运动，集成到 MPPI 控制中。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ 这是最直接相关的工作之一。区别在于：他们聚焦于"推动障碍物"（NAMO 任务），而我们更关注"铰接对象操作"（开门、开冰箱等）。

#### [7] Manipulate-to-Navigate: RL with Visual Affordances and Manipulability Priors
- **arXiv:** 2508.13151 (2025.08)
- **作者:** Yuying Zhang, Joni Pajarinen
- **核心贡献:** **直接相关！** 提出"先操作后导航"框架——操作可动物体以清除路径，然后导航通过。结合 manipulability prior 和 affordance map 选择操作策略。在 Boston Dynamics Spot 上验证了开门任务。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ 与我们的设想高度一致。但他们没有考虑在语义地图中持续维护交互信息，也没有考虑多步交互规划。

#### [8] HANDO: Hierarchical Autonomous Navigation and Dexterous Omni-loco-manipulation
- **arXiv:** 2510.09221 (2025.10)
- **作者:** Jingyuan Sun et al.
- **核心贡献:** 两层框架：上层 goal-conditioned 自主导航探索，下层统一全身 loco-manipulation 策略。在腿式机器人+机械臂平台上实现。
- **与本项目的关联:** ⭐⭐⭐⭐ 层次化架构（导航层 + 操作层）与我们的设想一致。可以作为框架设计参考。

#### [9] Interactive Navigation for Legged Manipulators with Learned Arm-Pushing Controller
- **arXiv:** 2503.01474 (2025.03)
- **作者:** Zhihai Bi et al.
- **核心贡献:** 针对腿式机械臂的 interactive navigation 框架，使用手臂推动机制在狭窄空间中移动障碍物。两阶段奖励策略（到达推动区域 → 稳定推动）。
- **与本项目的关联:** ⭐⭐⭐⭐ 提供了交互操作的 RL 训练方法参考。

### 2.3 开放词汇移动操作 (OVMM)

#### [10] Open-vocabulary Mobile Manipulation with 3D Semantic Maps (JSR-1)
- **arXiv:** 2406.18115 (2024.06)
- **作者:** Dicong Qiu et al.
- **核心贡献:** 完整的 OVMM 框架：VLM 零样本检测 → 3D 实体重建 → 语义地图 → LLM 空间推理 → 在线规划。在真实环境中 105 个 episode 达到 80.95% 导航成功率、73.33% 任务成功率。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ 提供了"VLM + 3D 语义地图 + LLM 规划"的完整 pipeline 参考，可以直接借鉴到交互式导航中。

#### [11] SAGA: Open-World Mobile Manipulation via Structured Affordance Grounding
- **arXiv:** 2512.12842 (2025.12)
- **作者:** Kuan Fang et al.
- **核心贡献:** 使用 affordance-based 任务表征，将高层语义意图与底层 visuomotor 控制解耦。通过 VLM 生成 3D affordance heatmap，训练条件策略实现全身控制。
- **与本项目的关联:** ⭐⭐⭐⭐ affordance grounding 的思路可以直接应用于"识别可交互对象的交互区域"。

#### [12] Affordance RAG: Hierarchical Multimodal Retrieval for Mobile Manipulation
- **arXiv:** 2512.18987 (2025.12)
- **作者:** Ryosuke Korekata et al.
- **核心贡献:** 零样本层次化多模态检索框架，从预探索图像构建 Affordance-Aware Embodied Memory。通过区域语义 + affordance score 重排候选目标。真实环境成功率 85%。
- **与本项目的关联:** ⭐⭐⭐⭐ "Affordance-Aware Memory" 概念可以直接应用——将交互对象的 affordance 存储在地图记忆中。

#### [13] Affordance-Guided Coarse-to-Fine Exploration for Base Placement in OVMM
- **arXiv:** 2511.06240 (2025.11)
- **作者:** Tzu-Jung Lin et al.
- **核心贡献:** 零样本 base placement 框架，通过 VLM 语义先验 + 几何约束的迭代优化选择操作位置。构建 Affordance RGB 和 Obstacle Map+ 跨模态表征。
- **与本项目的关联:** ⭐⭐⭐ 在交互操作时选择合适的 base 位置是关键子问题。

### 2.4 铰接对象操作 (Articulated Object Manipulation)

#### [14] SAGE: Bridging Semantic and Actionable Parts for Articulated Object Manipulation
- **arXiv:** 2312.01307 (2023.12)
- **作者:** Haoran Geng et al. (UCLA/Stanford)
- **核心贡献:** 桥接语义部件和可操作部件（GAParts）。VLM 理解自然语言指令 → 提出 action program → 部件 grounding → 末端执行器轨迹预测。在多种铰接对象上验证。
- **与本项目的关联:** ⭐⭐⭐⭐⭐ GAPart 概念对我们的交互层设计至关重要——在语义地图中标注每个对象的 GAPart 及其运动属性。

#### [15] UniDoorManip: Universal Door Manipulation Policy
- **arXiv:** 2403.02604 (2024.03)
- **作者:** Yu Li et al. (PKU)
- **核心贡献:** 大规模多样化门操作环境（6 类门、数百种门体和把手、上千实例）。三阶段框架（解锁 → 抓握 → 拉开），在移动机器人上使用部分点云观测。
- **与本项目的关联:** ⭐⭐⭐⭐ 门是最典型的交互对象。该工作提供了门操作的详细方法和 benchmark。

#### [16] ArtGS: 3D Gaussian Splatting for Articulated Object Manipulation
- **arXiv:** 2507.02600 (2025.07)
- **作者:** Qiaojun Yu et al.
- **核心贡献:** 将 3D Gaussian Splatting 扩展到铰接对象，通过 VLM 推理语义结构 + 动态可微渲染优化关节参数。实现物理一致的运动约束。
- **与本项目的关联:** ⭐⭐⭐⭐ 提供了交互对象运动模型的精确估计方法。

#### [17] GAPartManip: Part-centric Dataset for Articulated Object Manipulation
- **arXiv:** 2411.18276 (2024.11)
- **作者:** Wenbo Cui et al. (PKU)
- **核心贡献:** 大规模以部件为中心的数据集，包含照片级真实感材质随机化和详细的部件级交互姿态标注。
- **与本项目的关联:** ⭐⭐⭐ 提供训练数据参考。

### 2.5 LLM/VLM 驱动的导航规划

#### [18] Embodied-RAG: General Non-parametric Embodied Memory
- **arXiv:** 2409.18313 (2024.09)
- **作者:** Quanting Xie et al. (CMU)
- **核心贡献:** 将 RAG 概念引入 embodied domain，构建层次化语义记忆（语义森林结构），支持不同粒度的空间和语义查询。在公里级环境中验证了 250+ 导航和解释查询。
- **与本项目的关联:** ⭐⭐⭐⭐ 层次化记忆结构可以用于存储"哪些区域有可交互对象"的经验知识。

#### [19] osmAG-LLM: Zero-Shot Object Navigation via Semantic Maps and LLM Reasoning
- **arXiv:** 2507.12753 (2025.07)
- **作者:** Fujing Xie et al.
- **核心贡献:** 考虑对象位置动态变化或未被地图记录的情况，结合语义地图 + LLM 常识推理预测对象位置，主动在线搜索。
- **与本项目的关联:** ⭐⭐⭐⭐ 当可交互对象的位置不确定时，LLM 推理非常关键（如"门后面可能是另一个房间"）。

#### [20] LongNav-R1: Multi-Turn RL for Long-Horizon VLA Navigation
- **arXiv:** 2602.12351 (2026.02)
- **作者:** Yue Hu et al.
- **核心贡献:** 将导航决策建模为 VLA 策略与环境的多轮对话，引入 Horizon-Adaptive Policy Optimization 处理长时序任务。
- **与本项目的关联:** ⭐⭐⭐ 多轮交互式决策框架可以扩展到导航+交互的交替执行。

## 3. 关键发现与研究空白

### 3.1 已有工作的共同模式

| 维度 | 现有方案 | 本项目的差异化 |
|------|---------|---------------|
| 地图表征 | 3D 语义地图 / 场景图 | 在场景图上增加**交互属性边** |
| 交互感知 | 单次 affordance 检测 | 持续维护交互状态（门开了/关了） |
| 任务规划 | 导航 OR 操作 | 导航 → 交互 → 导航 的交替执行 |
| 对象类别 | 主要关注门/抽屉 | 扩展到冰箱、衣柜、微波炉等 |

### 3.2 研究空白 (Research Gaps)

1. **交互状态的持续跟踪**：现有工作大多将交互视为一次性事件，缺乏对"门已打开"等状态变化的持续跟踪和地图更新。
2. **多步交互链规划**：到达目标可能需要连续多次交互（打开走廊门 → 穿过走廊 → 打开冰箱），现有框架缺乏这种长链规划能力。
3. **交互代价建模**：不同交互操作的难度和时间成本不同（推门 vs 拉门 vs 输入密码），如何在导航规划中纳入交互代价？
4. **失败恢复**：交互操作可能失败（门锁了），需要在线重规划。现有工作对此关注不足。
5. **统一的地图交互层设计**：如何在现有语义地图框架中优雅地增加交互层，而非 ad-hoc 扩展？

### 3.3 最相关的工作 TOP 5

| 排名 | 论文 | 理由 |
|------|------|------|
| 1 | Manipulate-to-Navigate (2508.13151) | 最接近"先操作后导航"的核心思路 |

## 4. 建议的技术路线

### Phase 1: 基础设施
- 选定语义地图框架（推荐基于 HOV-SG 或 OSG 扩展）
- 实现 open-vocabulary 交互对象检测（门、冰箱、衣柜等）
- 构建交互属性标注模块（可开/可推/可拉等）

### Phase 2: 交互层设计
- 设计场景图的交互边（interaction edge）数据结构
- 实现交互状态跟踪（开/关/锁等）
- 集成 affordance grounding（如 SAGE 的 GAPart 概念）

### Phase 3: 规划与执行
- 实现 LLM 驱动的多步交互-导航联合规划
- 集成移动操作策略（参考 Manipulate-to-Navigate）
- 失败检测与重规划机制

### Phase 4: 评估
- 仿真环境：推荐 BEHAVIOR-1K 或 Habitat
- 真实环境：构建包含多种交互对象的测试场景
- 评估指标：导航成功率、交互成功率、路径效率、任务完成时间
