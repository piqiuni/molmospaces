# 14通道输入格式详细说明

## 输入格式总览

### 基本格式
- **形状 (Shape)**: `(C, H, W)`
  - `C = 14`: 通道数（固定为14）
  - `H`: 高度（Height），地图的垂直像素数
  - `W`: 宽度（Width），地图的水平像素数
- **数据类型**: `numpy.ndarray`
- **数值类型**: `uint8` (0-255) 或 `float32` (0.0-1.0)
- **数值范围**: 
  - `uint8`: 0-255（函数会自动归一化到0.0-1.0）
  - `float32`: 0.0-1.0（直接使用）

### 输入示例
```python
import numpy as np

# 创建14通道输入
H, W = 256, 256  # 地图尺寸（根据实际情况设置）
full_map = np.zeros((14, H, W), dtype=np.uint8)  # 形状: (14, 256, 256)

# 或者使用float32
full_map = np.zeros((14, H, W), dtype=np.float32)  # 形状: (14, 256, 256)
```

### 维度说明
- **第0维 (C)**: 通道维度，固定为14
  - `full_map[0]` → 通道0（占用图），形状: `(H, W)`
  - `full_map[1]` → 通道1（探索掩码），形状: `(H, W)`
  - `full_map[2]` → 通道2（智能体位置），形状: `(H, W)`
  - `full_map[3]` → 通道3（历史轨迹），形状: `(H, W)`
  - `full_map[4:14]` → 通道4-13（语义概率），形状: `(10, H, W)`

- **第1维 (H)**: 高度维度，地图的垂直方向
  - `full_map[:, y, :]` → 第y行的所有通道数据

- **第2维 (W)**: 宽度维度，地图的水平方向
  - `full_map[:, :, x]` → 第x列的所有通道数据

### 访问单个像素
```python
# 访问位置(x, y)的所有通道
pixel_channels = full_map[:, y, x]  # 形状: (14,)

# 访问特定通道在位置(x, y)的值
occupancy_value = full_map[0, y, x]  # 占用图的值
explored_value = full_map[1, y, x]    # 探索掩码的值
semantic_value = full_map[5, y, x]    # 卧室（类别1）的概率值
```

### 输入验证
```python
def validate_input(full_map):
    """验证输入格式是否正确"""
    assert isinstance(full_map, np.ndarray), "输入必须是numpy数组"
    assert full_map.ndim == 3, f"输入维度错误，应该是3维 (C, H, W)，实际是 {full_map.ndim} 维"
    assert full_map.shape[0] == 14, f"通道数错误，应该是14，实际是 {full_map.shape[0]}"
    assert full_map.dtype in [np.uint8, np.float32, np.float64], \
        f"数据类型错误，应该是uint8或float32/64，实际是 {full_map.dtype}"
    
    C, H, W = full_map.shape
    print(f"✓ 输入验证通过")
    print(f"  形状: (C={C}, H={H}, W={W})")
    print(f"  数据类型: {full_map.dtype}")
    print(f"  数值范围: [{full_map.min():.2f}, {full_map.max():.2f}]")
    return True
```

## 通道索引和含义

### 通道0: 占用图 (Occupancy Map)
**数值含义：**
- `0`: 自由空间（可通行）
- `> 0` (通常是 `255`): 占用/障碍物（不可通行）
- 范围：`0-255` (uint8) 或 `0.0-1.0` (float32)

**用途：** 告诉模型哪些区域是障碍物，哪些是可通行区域

**示例：**
```python
full_map[0, y, x] = 255  # 位置(x,y)是障碍物
full_map[0, y, x] = 0    # 位置(x,y)是自由空间
```

---

### 通道1: 探索掩码 (Explored Mask)
**数值含义：**
- `0`: 未探索区域
- `> 0` (通常是 `255`): 已探索区域
- 范围：`0-255` (uint8) 或 `0.0-1.0` (float32)

**用途：** 区分已探索和未探索区域，模型主要预测未探索区域

**代码中的使用：**
```python
explored_mask = current_frame[1] > 0  # 已探索区域
unexplored_mask = ~explored_mask      # 未探索区域
```

**示例：**
```python
full_map[1, y, x] = 255  # 位置(x,y)已探索
full_map[1, y, x] = 0    # 位置(x,y)未探索
```

---

### 通道2: 智能体位置 (Agent Position)
**数值含义：**
- `0`: 智能体不在该位置
- `> 0` (通常是 `255`): 智能体在该位置（可能是概率或热力图）
- 范围：`0-255` (uint8) 或 `0.0-1.0` (float32)

**用途：** 标记智能体当前位置

**代码中的使用：**
```python
agent_pose = current_frame[2]
if np.any(agent_pose > 0):
    agent_pos = np.unravel_index(np.argmax(agent_pose), agent_pose.shape)
    # 找到最大值的位置，即智能体位置
```

**示例：**
```python
# 方法1: 单点位置（推荐）
full_map[2, agent_y, agent_x] = 255  # 智能体在(agent_x, agent_y)
full_map[2, :, :] = 0  # 其他位置为0

# 方法2: 概率热力图（如果位置不确定）
full_map[2, y, x] = 200  # 高概率位置
full_map[2, y+1, x] = 100  # 较低概率位置
```

---

### 通道3: 智能体历史轨迹 (Agent History)
**数值含义：**
- `0`: 智能体未经过该位置
- `> 0`: 智能体经过该位置的次数或强度
- 范围：`0-255` (uint8) 或 `0.0-1.0` (float32)

**用途：** 记录智能体的移动历史，帮助模型理解探索模式

**代码中的使用：**
```python
agent_history = current_frame[3]
# 直接使用，值越大表示经过次数越多或时间越近
```

**示例：**
```python
# 方法1: 二值化轨迹（简单）
full_map[3, trajectory_y, trajectory_x] = 255  # 经过的位置
full_map[3, :, :] = 0  # 未经过的位置

# 方法2: 累积轨迹（推荐，保留历史信息）
# 每次移动时，在当前位置加一个值
full_map[3, current_y, current_x] += 50  # 累积值
# 值越大表示经过次数越多
```

---

### 通道4-13: 语义类别概率图 (Semantic Probability Maps)
**数值含义：**
- `0`: 该位置不是该类别，或未探索区域
- `> 0`: 该位置是该类别的概率
- 范围：`0-255` (uint8) 或 `0.0-1.0` (float32)
- **注意：** 在已探索区域，这些值应该是真实的语义概率；在未探索区域，可以是0或之前预测的概率

**10个语义类别：**
- **通道4**: 类别0 - 客厅
- **通道5**: 类别1 - 卧室
- **通道6**: 类别2 - 厨房
- **通道7**: 类别3 - 洗手间
- **通道8**: 类别4 - 阳台
- **通道9**: 类别5 - 储藏间
- **通道10**: 类别6 - 门
- **通道11**: 类别7 - 墙
- **通道12**: 类别8 - 大门
- **通道13**: 类别9 - 外部区域

**代码中的使用：**
```python
gt_sem = gt_frame[4:14]  # 语义通道部分 shape: (10, H, W)
gt_sem_label = np.argmax(gt_sem, axis=0)  # 取最大概率对应的类别
```

**示例：**
```python
# 在已探索区域填入真实语义概率
explored_mask = full_map[1] > 0

# 方法1: One-hot编码（推荐，如果知道确切类别）
if explored_mask[y, x]:
    true_class = 1  # 假设是卧室
    full_map[4 + true_class, y, x] = 255  # 卧室通道设为255
    # 其他类别通道保持为0

# 方法2: 概率分布（如果有多类别概率）
if explored_mask[y, x]:
    full_map[5, y, x] = 200  # 卧室概率 200/255 ≈ 0.78
    full_map[6, y, x] = 50   # 厨房概率 50/255 ≈ 0.20
    # 其他类别为0

# 未探索区域保持为0（模型会预测）
```

## 完整示例

```python
import numpy as np

H, W = 256, 256
full_map = np.zeros((14, H, W), dtype=np.uint8)

# 通道0: 占用图
# 设置边界为障碍物
full_map[0, :10, :] = 255  # 上边界
full_map[0, -10:, :] = 255  # 下边界
full_map[0, :, :10] = 255  # 左边界
full_map[0, :, -10:] = 255  # 右边界

# 通道1: 探索掩码
# 假设已探索左上角区域
full_map[1, :H//2, :W//2] = 255

# 通道2: 智能体位置
agent_x, agent_y = 100, 100
full_map[2, agent_y, agent_x] = 255

# 通道3: 智能体历史轨迹
# 假设智能体从(50,50)移动到(100,100)
for i in range(50, 101):
    full_map[3, i, i] = 255

# 通道4-13: 语义概率图
# 在已探索区域填入真实语义
explored_mask = full_map[1] > 0

# 假设已探索区域中，左上角是卧室
full_map[5, :H//4, :W//4] = 255  # 卧室

# 假设边界是墙
full_map[11, :10, :] = 255  # 上边界是墙
full_map[11, -10:, :] = 255  # 下边界是墙
full_map[11, :, :10] = 255  # 左边界是墙
full_map[11, :, -10:] = 255  # 右边界是墙

# 未探索区域保持为0（模型会预测这些区域）
```

## 数值范围总结

| 通道 | 含义 | 数值范围 | 典型值 |
|------|------|----------|--------|
| 0 | 占用图 | 0-255 | 0=自由, 255=障碍 |
| 1 | 探索掩码 | 0-255 | 0=未探索, 255=已探索 |
| 2 | 智能体位置 | 0-255 | 0=不在, 255=在 |
| 3 | 历史轨迹 | 0-255 | 0=未经过, >0=经过次数 |
| 4-13 | 语义概率 | 0-255 | 0=不是该类别, 255=高概率是该类别 |

**归一化：**
- 如果输入是 `uint8` (0-255)，函数会自动归一化到 `0.0-1.0`
- 如果输入已经是 `float32` (0.0-1.0)，则直接使用

---

## 注意事项

1. **已探索区域的语义：** 通道4-13在已探索区域应该填入真实的语义概率（ground truth）
2. **未探索区域的语义：** 通道4-13在未探索区域可以是0，或者填入之前预测的概率
3. **数值一致性：** 建议所有通道使用相同的数值范围（要么都是0-255，要么都是0.0-1.0）
4. **智能体位置：** 如果位置不确定，可以使用概率热力图；如果位置确定，使用单点（推荐）
